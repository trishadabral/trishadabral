# SVG section usage

Upload the `assets/` folder to your profile repository, then use:

```md
<p align="center">
  <img src="./assets/01-hero.svg" alt="Trisha Dabral — AI Full Stack Developer" width="100%" />
</p>

<img src="./assets/02-technical-profile.svg" alt="Technical Profile" width="100%" />

## Technical Profile
<!-- Keep the actual section text here in Markdown -->

<img src="./assets/03-tech-stack.svg" alt="Tech Stack" width="100%" />

## Tech Stack
<!-- Real badges/icons go here -->

<img src="./assets/04-selected-work.svg" alt="Selected Work" width="100%" />

## Selected Work
<!-- Tutor AI, SkillLens, Cognisafe -->

<img src="./assets/05-engineering-signals.svg" alt="Engineering Signals" width="100%" />

## Engineering Signals
<!-- 200+ DSA, Hackathon, etc. -->

<img src="./assets/06-certifications.svg" alt="Certifications" width="100%" />

## Certifications
<!-- Oracle + IBM -->

<img src="./assets/07-connect.svg" alt="Connect" width="100%" />

## Connect
<!-- LinkedIn / GitHub / LeetCode / Email -->
```

Important:
- Keep real text, links, badges, and project details in Markdown/HTML below each SVG.
- Use the SVGs as section visuals, not as the only source of content.
- The SVG files use no JavaScript and no external libraries.
